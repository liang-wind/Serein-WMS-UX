## H. 实施纪律（从编码事故与并发冲突中总结）

1. **禁止用 PowerShell 读写 `wms/` 下 UTF-8 文件**，一律 edit/write 工具。
2. 每完成一页，浏览器实测：控制台零错误 + DOM 关键节点存在 + 交互跑通。
3. 新页面必须接入既有 `WMS.RENDER` / `WMS.OPS` / `WMS.ACTIONS` / `STATUS_BY`，不得另起炉灶。
4. 新 `ACTIONS` 里调 `formModal` 时，契约是 `options` / `required` / `help` / `ok` / `onSubmit`（曾因键名写错导致下拉全空）。
5. 组件只从 `wms.css` 既有 class 取用，不新增色板、不新增圆角刻度。
6. 每页数据标注「演示数据」，不做无来源的伪精确数字。
